## Three rules that do not bend
1. **Every answer shows its evidence.** Citations, confidence and the verdict sit next to the answer.
2. **Every call leaves a receipt.** The UI can open the decision behind any answer. It never shows the input text, because the platform does not store it.
3. **Nothing waits for no reason.** Feedback starts on press. Motion is interruptible. No artificial delays.

## History

These parts of version 1 are still true and were kept: calm confidence as the goal, the neutral and brand tokens, the confidence scale, the type scale and casing rules, materials and depth, the motion rules (feedback on press, interruptible, transform and opacity only), and the accessibility rules.

What changed in version 2:

| Version 1 | Version 2 |
|---|---|
| Four destinations: Ask, Library, Insights, System | Three groups with eleven screens, plus the landing page and sign-in |
| Preview key added by nginx | A session cookie from `POST /v1/session`. No key in the browser or the proxy |
| CSS modules | Tailwind on the token variables, with shadcn/ui patterns |
| Inter and JetBrains Mono | Geist Sans and Geist Mono |
| Lucide icons | Phosphor icons |
| One collection picker in the top bar | A knowledge base field on Ask and Library. The field accepts any slug, so a person can see a denial |
| Plain JavaScript | TypeScript in strict mode, with a client generated from the OpenAPI file |

The old logo and mode badge rules still hold. The logo is a rounded square with three lines, the last one shorter and ending in a dot in `--brand` (replaced by the seal color in version 3). The mode chip in the top bar shows `public-preview`, `local` or `prod`, and adds "read-only" for a preview session.

### Version 3 (Sprint 005b)

| Version 2 | Version 3 |
|---|---|
| Blue brand accent (`--brand`) | Ink and paper, one seal color, verdicts as the only strong color (ADR-0010) |
| `tokens.css` edited by hand, tables in this file | `ui/tokens/tokens.json` in the W3C format, CSS generated by Style Dictionary, CI fails on drift |
| One long guidelines file | The `docs/design/` set, with this file as the index |
| Landing page led with the mechanism | The headline "Your agents can only ever do less.", use cases, and a How it works page |
| Decisions as a flat list | Requests grouped by request, a slide-over drawer, deny emphasis with a plain sentence and the policy field |
| No first-run guide | The walkthrough: one allowed and one blocked request side by side |
| Sign out and theme as icon buttons | A session menu and a Cmd or Ctrl plus K palette |
| Hand-checked color use | ESLint and a test fail on color literals, and a test checks every contrast pair |

The logo is still a rounded square with three lines, the last shorter and ending in a dot. The dot is now the seal color.
