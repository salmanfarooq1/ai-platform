# Sprint 012: Architect disposition

This resolves the readiness audit against the current code. Implement only after Sprint 011 acceptance and its prerequisite snapshot are recorded.

1. **Identity first.** The pipeline is `principal`, `module`, `boundary`, then the existing stages. The principal stage checks presence only; preserve existing route scope dependencies and middleware before enforcement. Unknown credentials retain 401, missing scopes retain 403. An authenticated, scoped call to an off module gets a recorded 404 `module_disabled`. The module stage cannot reveal configuration to unauthenticated callers.
2. **Evidence core is mandatory.** Production always builds `PgDecisionSink` and `PgEvidenceLookup`, including Gateway edition with M2 off. M2 means optional assurance features, never basic recording or receipts. A synthetic unavailable sink raises for failure tests; no successful no-op sink exists.
3. **Typed ports precede moves.** Use the exact asynchronous contracts below. The sink owns row identity, timestamps, chain ordering and transactional publication. It imports no gateway types. Preserve allow/deny publication and recording failure behavior.
4. **Preserve history.** Canonical v1 contains exactly the existing 13 fields, excluding `trace_id`: `id`, `tenant_id`, `principal_id`, `request_id`, `action`, `resource`, `outcome`, `stage`, `reason`, `policy_version`, `input_sha256`, `execution_id`, `created_at`. Retain UTF-8 `ensure_ascii=False`, sorted keys, compact separators and the UTC timestamp with six fractional digits followed by `Z`. V2 adds only `record_version: 2` and `extensions`. API defaults for old rows never enter their v1 signature. Require v1 extensions to be empty in the database, receipt projection and both verifiers: attaching unsigned extension claims to a valid old receipt must fail, even though its original 13-field signature still matches. Deep-copy and freeze extensions at construction; recursively reject floats, non-finite numbers, non-string object keys, unknown registered keys and canonical UTF-8 size above 4096 bytes before persistence. New registry starts empty.
5. **Single tenant remains isolated.** Enforce the shape at startup and owner-CLI tenant creation. The startup probe is a narrow SECURITY DEFINER boolean returning whether multiple tenants exist, fixed trusted search path with `pg_temp` last and schema-qualified persistent relations, PUBLIC revoked, executable only by `gap_app`. A caller-created temporary table must not shadow the tenant probe or claim queries. It returns no tenant identity or row. Serialize CLI count/create with a transaction advisory lock to prevent concurrent second tenants. Never disable RLS; fixtures intentionally needing two tenants select `multi_tenant`. The migration's default tenant counts as a tenant.
6. **Disabled jobs remain unclaimed.** The worker passes registered job kinds into the claim function. Add a three-argument `jobs_claim(worker, lease, allowed_kinds)` with no implicit wildcard; NULL/empty lists claim nothing. Filter both ordinary claims and expired-lease maintenance by allowed kinds. Revoke app/PUBLIC execution on the old unfiltered overload. Preserve leases, SKIP LOCKED and idempotency. Prove queued and expired disabled jobs remain unchanged while enabled work proceeds.
7. **Load only enabled execution code.** Agent, sandbox and MCP route prefixes belong to M3. Add trusted `required_module` context attribution from the registered route/deny wrapper, never from headers, body, query, model arguments or run-token input. The module stage checks both this attribution and the action map: agent-run reads use `audit.read`/`kb.read`, sandbox models use `model.invoke`, and MCP opening uses `kb.read`, so the action alone is insufficient. The disabled-route manifest retains exact methods, entry actions and credential dependencies: agent query requires `agent`; run reads require `agent` OR `audit:read`; sandbox calls require a matching run grant for the execution id; MCP middleware requires `query` OR `kb:read`. Keep existing ingest, KB/search, decisions, receipts, metrics and purge in the always-on foundation. The registry loads agent job construction from `api.agent.jobs`; the generic worker context does not import agent code. With M3 off, do not import/build graphs, MCP servers or OpenShell runtimes. Move eager OpenShell adapter imports inside the enabled factory and dynamically load sandbox routes. A typed raising disabled AgentRuntime may fill the bundle. Test import absence in a fresh subprocess because pytest collection imports agent tests. Expose needed estimate/usage/cost/reason/context helpers through the gateway package API before replacing internal imports.
8. **Lineage staging.** In 012, the no-op emitter drops and counts events; there are no production lineage producers yet. Counts are process observability, never durable evidence. Sprint 022 must add a tenant-scoped durable spool behind the port before its first producer ships; 025 consumes it. Do not describe an in-memory collection as a spool.
9. **Tests and UI.** Capture a full green pure-move checkpoint with existing expected behavior. Later fixtures, injections and signatures may change for the explicit new contracts, without dropping assertions or old coverage. Add tests for intentional new behavior. Historical migration-0008 privilege tests target revision 0008 explicitly, retaining their assertions; the new migration separately proves the old overload is revoked. Update direct claim callers to pass allowed kinds. Version-aware database export and both online/offline verification project canonical fields explicitly and reject unsupported record versions. There is no current tenant switcher to invent or remove; preserve the identity display. Refresh module nav metadata with session identity and fail closed while it is unavailable. Insights is introduced in 029, not 028. SideNav and CommandPalette share the same filtered navigation; the palette must not retain a module-level unfiltered screen list.

10. **Metadata permission:** select `ActionKind.SYSTEM_READ = "system.read"`, mapped to gateway and granted by every recognized existing scope. `/v1/system/modules` authenticates with the scope union and enforces this fixed action on `system/modules`. Unknown/empty scopes stay 403; missing credentials stay 401; run tokens retain path binding. Do not grant KB/model/audit actions to make metadata visible or label metadata reads as writes. A narrowed boundary may remove system.read. Prove each single-scope credential receives metadata without gaining any old action.

## Port contracts

All methods are `async`; all value records are frozen dataclasses in `ports/`, without SDK or platform imports. Define `JsonValue` there. Extension validation is stricter than generic JSON results.

- `DecisionEntry`: `tenant_id: UUID`, `principal_id: UUID | None`, `request_id: str`, `trace_id: str`, `action: str`, `resource: str | None`, `outcome: Literal["allow", "deny"]`, `stage: str`, `reason: str`, `policy_version: int | None`, `input_sha256: str | None`, `execution_id: UUID | None`, `extensions: Mapping[str, JsonValue]`. No gateway `Action`, `Decision` or context object crosses this port.
- `DecisionSink.write(entry: DecisionEntry, events: EventBus | None = None) -> UUID`. Raises on failure. Preserve transactional outbox behavior and tenant chain lock.
- `EvidenceLookup.decision(tenant_id: UUID, decision_id: UUID) -> EvidenceRef`, with `EvidenceRef(linked: bool, decision_id: UUID | None = None, href: str | None = None)`. Unknown and foreign ids return identical unlinked values. The real lookup remains available with M2 off; a no-op adapter is only a port-contract fixture.
- `DataAccess.read(*, tenant_id: UUID, resource: str) -> DataResult`, with `DataResult(columns: tuple[str, ...], rows: tuple[Mapping[str, JsonValue], ...], snapshot_id: str | None = None)`. No-op raises `ModuleDisabled` from `ports/errors.py`. There is no real adapter in 012; 021 evolves this contract to include verified authority/grants before use. Tenant/resource arguments alone never authorize data access.
- `LineageEmitter.emit(event: CloudEvent, *, tx: Any = None) -> None`. Use the existing CloudEvent contract. No-op increments `dropped_count`; no publication is claimed. Transaction support allows the later durable spool to commit with the producer's change.
