# Sprint 005: Blueprint (contract first)

The contract below is fixed before either builder starts. A change to it needs the Architect's approval and an update to this file.

## 1. Auth additions
- **Scope:** new `audit:read` in `core/identity/models.py`. `admin` still satisfies every scope.
- **Action:** new `audit.read` in `gateway/types.py`. The scope map grants `audit.read` to `audit:read`.
- **Policy:** a policy can't narrow `audit.read` by resource. Same rule as `analytics.read`.
- **Decision rows:** every console read calls `enforce(Action(AUDIT_READ, <resource>))` and so writes a decision row. The resource is one of `decisions`, `policies`, `principals` or `usage`.
- **Admin CLI:** `scripts/admin/identity.py create-key` accepts `audit:read`.

## 2. Web edge: `api/web_edge/` (ADR-0007)
Sessions live in Redis under `websess:<sha256(session_id)>`. The value is JSON: `{principal_id, tenant_id, scopes, csrf, created_at, preview}`. The TTL is 8 h, sliding on use, and there's an absolute cap of 24 h. The session id is 32 random bytes (urlsafe). Cookie: `gap_session`, HttpOnly, SameSite=Strict, Path=/, Secure unless `MODE=local`.

| Method | Path | Body | Response | Notes |
|---|---|---|---|---|
| POST | `/v1/session` | `{"api_key": str}` | 200 `SessionInfo` + Set-Cookie | Bad key gives 401 `invalid_credentials` with one generic message. Not rate-limited by principal; rate-limited by client IP (10/min) |
| GET | `/v1/session` | | 200 `SessionInfo`, or 401 | |
| DELETE | `/v1/session` | | 204, cookie cleared | Needs CSRF |
| POST | `/v1/session/preview` | | 200 `SessionInfo` + Set-Cookie | Only when `MODE=public-preview` and `PREVIEW_PRINCIPAL_ID` is set; else 404 `not_found`. Scopes are the principal's scopes minus `kb:write` and `admin` |

`SessionInfo` = `{principal: {id, name, kind}, tenant: {id, slug}, scopes: [str], csrf_token: str, preview: bool, expires_at: datetime}`

**Auth middleware order:**
1. A bearer key or JWT.
2. Otherwise the `gap_session` cookie.
3. Otherwise 401.

With a cookie session, unsafe methods need the `X-CSRF-Token` header to equal the session's `csrf`, else 403 `csrf_failed`. Bearer requests don't need CSRF. A session resolves to the same principal object as a key, so `enforce()` and RLS are unchanged.

`PREVIEW_PRINCIPAL_ID` is a setting in `core/settings.py`, not a CLI command. The nginx key injection is removed when the old UI goes (requirement 8).

## 3. Console read endpoints (all GET, all `audit:read`)

| Path | Query | Response |
|---|---|---|
| `/v1/decisions` | `outcome` (allow\|deny), `action`, `principal_id`, `policy_version`, `request_id`, `since`, `until`, `cursor`, `limit` (1-200, default 50) | `DecisionPage {items: [DecisionSummary], next_cursor: str\|null}` sorted by `created_at desc, id desc` |
| `/v1/decisions/{id}` | | `DecisionDetail`, or 404 `not_found` (foreign or missing gives the same body) |
| `/v1/policies` | | `[PolicyVersion]` newest first; empty list if none, plus `default_in_effect: bool` in a wrapper `PolicyList {versions, default_in_effect}` |
| `/v1/policies/{version}` | | `PolicyVersion` or 404 |
| `/v1/principals` | | `[PrincipalSummary]` |
| `/v1/usage/summary` | `days` (1-90, default 7) | `UsageSummary` |

**Models** (Pydantic, in `api/models/console.py`):
- `DecisionSummary {id, created_at, request_id, principal: {id, name}, action, resource, outcome: "allow"|"deny", stage, reason, policy_version: int|null}`
- `DecisionDetail = DecisionSummary + {tenant: {id, slug}, input_sha256: str|null, trace: [DecisionSummary]}`
  - `trace` holds every decision with the same `request_id`, oldest first. It's capped at 200.
- `PolicyVersion {version, active: bool, created_at, created_by: str|null, document: {allowed_kbs, allowed_tools, allowed_models, max_tool_calls, max_tokens_per_request}}`
- `PrincipalSummary {id, name, kind, created_at, keys: [{prefix, scopes, created_at, last_used_at, revoked: bool}]}`
  - No hash, no secret and no part of the key after the prefix.
- `UsageSummary {days, totals: {requests, tokens, cost_usd}, by_principal: [{principal: {id, name}, requests, tokens, cost_usd}], by_day: [{date, requests, tokens, cost_usd}], denied: {rate, budget, policy}}`
  - `denied` counts come from `gateway_decisions`.

**Cursor:** opaque base64 of `(created_at, id)`. A bad cursor gives 400 `invalid_cursor`.

**Contract rules:**
- If a column doesn't exist (for example `last_used_at` or `created_by`), return null and note it in the report. Don't invent data.
- All reads run inside `tenant_connection` as `gap_app`. No new grants beyond SELECT.
- Errors use the standard error format.

## 4. Frontend architecture (`ui/`)
- **Layout:**
  - `src/app` holds the router and providers.
  - `src/api` holds `schema.d.ts`, generated by `npm run gen:api` from `../docs/openapi.json`, and a typed fetch client.
    - The client sends cookies (`credentials: 'include'`) and `X-CSRF-Token` on unsafe methods.
    - It maps the error format into a typed `ApiError`.
  - `src/features/<area>` holds the screens.
  - `src/components/ui` holds the shadcn components.
  - `src/landing` holds the landing page, lazy-loaded with its own chunk.
- **Routes:**
  - `/` is the landing page.
  - `/app/ask`, `/app/library` and `/app/history` are the workspace.
  - `/app/decisions` and `/app/decisions/:id` are the Decisions explorer.
  - `/app/policies`, `/app/keys`, `/app/usage`, `/app/runs`, `/app/trust` and `/app/system` are the rest of the app.
  - `/signin` is the sign-in screen.
  - `/app/*` without a session redirects to `/signin`. In preview mode, `/signin` offers "Continue in read-only preview".
- **Agent runs:** built from decisions grouped by `request_id` where the action is `agent.run`, until Sprint 007 or 009 adds a runs API. Not a new endpoint.
- **History:** a client-side list of this browser's asks (localStorage), each linking to its decision trace by `request_id`.
- **Dev proxy:** Vite proxies `/v1` to `http://localhost:8000`, so cookies are same-site.

## 5. Test seam for the cross-stack e2e
`scripts/e2e/serve.py` starts the real app with the LLM and embedding fakes from `tests/fakes.py` patched in. It seeds a tenant, a principal and a key (`audit:read query kb:read agent`) and a policy, and prints the key to a file under `ui/e2e/.state/`, which is gitignored. Playwright's `webServer` starts it and `vite preview`. Real Postgres and Redis. Product code gets no fake switch.

## 6. Approved deviations (after the backend build)
- **Migration `0006`:** adds `auth_lookup_preview(principal_id)`, a narrow SECURITY DEFINER lookup in the same pattern as 0002 and 0003. It's needed because the preview lookup runs before a tenant is known.
- **`GET /v1/decisions` filters by `principal`, not `principal_id`.** An existing test forbids any parameter named `principal_id`.
- **Nullable fields:** `DecisionSummary.principal` and `PrincipalRef.name` can be null.
- **CSRF:** it applies to every cookie-session method except GET, HEAD and OPTIONS.
